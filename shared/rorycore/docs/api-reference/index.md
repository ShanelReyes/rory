# API Reference

Rory Core exposes the following modules as public API:

| Module | Description |
|--------|-------------|
| [Security](security.md) | Cryptosystems (CKKS, Paillier, Liu, FD-HOPE) and Data Owners |
| [Clustering](clustering.md) | KMeans, NNC, and their secure variants |
| [Classification](classification.md) | KNN, Logistic Regression, Secure KNN, and PPLR |
| [Utils](utils.md) | Helpers, constants, interfaces, and validation metrics |
